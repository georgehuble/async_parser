# Глоссарий

Единая терминология проекта (shared vocabulary). Термины должны использоваться
одинаково в спецификациях, коде и обсуждениях. Один термин — одно значение.

| Термин                  | Определение                                                                        |
| ----------------------- | ---------------------------------------------------------------------------------- |
| SPIMEX / СПбМТСБ        | Санкт-Петербургская Международная Товарно-сырьевая Биржа — источник данных.        |
| Бюллетень               | Документ по итогам торгов (XLS/PDF), скачиваемый с сайта биржи.                    |
| Сделка (`Trade`)        | Запись в таблице `trades`: объём, сумма, количество по одному нефтепродукту.       |
| `exchange_trade_id`     | Бизнес-идентификатор сделки на бирже.                                              |
| Базис поставки          | Код условия поставки (например `NAS`), справочник `delivery_bases`.                |
| Тип поставки            | Код типа поставки (например `G`), справочник `delivery_types`.                     |
| Нефтепродукт            | Товар из бюллетеня, справочник `oil_products`.                                     |
| `StopReason`            | Причина остановки пагинации: `CONTINUE`, `CUTOFF`, `MAX_DATE`.                     |
| `CUTOFF_YEAR`           | Предельный год: страницы с датами <= года не обрабатываются.                       |
| `max_date`              | Максимальная дата в БД; парсинг останавливается на датах <= `max_date`.            |
| Fetch                   | Компонент, который ходит по HTTP и перебирает пагинацию.                           |
| Parser                  | Компонент, который разбирает HTML (без сетевых запросов).                          |
| Downloader              | Компонент, который скачивает файлы бюллетеней и обновляет `file_path`.             |
| Бизнес-ключ             | Натуральный ключ записи (например `(exchange_id, url)`), в отличие от суррогатного `trade_id`. |

## Правила

- Новый термин появляется в глоссарии раньше, чем в спецификации.
- Если значения термина расходятся в разных местах — это сигнал к рефакторингу.
