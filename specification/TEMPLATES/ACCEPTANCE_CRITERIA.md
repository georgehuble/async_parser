# Критерии приёмки (шаблон)

<!-- Заполняйте критерии приёмки в стиле Given-When-Then.
     Один критерий — одна проверяемая ситуация. -->

## Правила

- Критерий формулируется без знания внутренней реализации.
- Используйте конкретные значения, а не общие слова.
- Каждый критерий должен быть покрыт автотестом.

## Шаблон

```gherkin
Scenario: <название>
  Given <предусловие>
  When <действие>
  Then <ожидаемый результат>

Scenario: <граничный случай>
  Given ...
  And ...
  When ...
  Then ...
  And ...
```

## Пример

```gherkin
Scenario: повторная ссылка не добавляется в БД
  Given в БД есть бюллетень с url="https://spimex.com/…/oil_20241217162000.pdf"
  And exchange_id=1
  When парсер возвращает этот url повторно
  Then в таблице trades остаётся ровно одна запись с этим url
  And запись имеет тот же trade_id
```

## Контрольный список

- [ ] Есть основной сценарий (happy path)
- [ ] Есть граничный случай
- [ ] Есть сценарий ошибки
- [ ] Нет зависимостей от деталей реализации
