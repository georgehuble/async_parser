# Спецификации

Здесь лежат черновые и утверждённые спецификации проекта.

## Правила добавления

1. Копия шаблона из `TEMPLATES/` (обычно `FEATURE.md`).
2. Имя файла: `NNN-kratkoe-nazvanie.md`, где `NNN` — следующий свободный номер.
3. В шапке проставляется статус `draft` и автор.
4. После ревью статус меняется на `approved`.
5. Утверждённая спецификация не редактируется молча: изменение требований —
   новая ревизия (новая спецификация со ссылкой на прежнюю).

## Статусы

| Статус        | Значение                                |
| ------------- | --------------------------------------- |
| `draft`       | Черновик, реализация запрещена          |
| `review`      | На ревью                                |
| `approved`    | Утверждена, можно реализовывать         |
| `implemented` | Код написан, тесты зелёные             |
| `done`        | Критерии приёмки подтверждены           |
